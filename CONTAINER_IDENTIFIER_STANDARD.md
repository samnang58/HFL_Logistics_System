# HFL Container & Tracking Identifier Standard

- Container Number: `YCL268899` — physical container number.
- HFL Tracking: `YC100200300` — generated by HFL when China warehouse physically receives the package.
- China Delivery Tracking: `8899006677100` — original China courier/delivery tracking number.
- HFL Package Code: separate internal package code, if used.

These identifiers must remain separate. Search in Containers supports all of them, and the UI labels them explicitly.

Container movement: Pending → Loading → Departed China → In Transit → Cambodia Port → Customs → Cambodia Warehouse → Received → Delivered.
